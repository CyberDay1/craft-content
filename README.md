# craft-content

Third-party content that the craft apps can download on request. Nothing here is our own work:
each file is an unmodified copy of something its author publishes under a licence that allows
redistribution, kept here so the apps can fetch it from a stable address.

Large files are attached to [releases](https://github.com/CyberDay1/craft-content/releases), not
committed. Each release also carries the file's licence, and the same licence is kept verbatim in
`licenses/`.

## Contents

### GeneralUser GS 2.0.3

- **What:** a General MIDI / GS SoundFont bank (`GeneralUser-GS.sf2`, 32,319,396 bytes).
- **Author:** S. Christian Collins, <https://www.schristiancollins.com/generaluser>
- **Source:** the author's repository, <https://github.com/mrbumpy409/GeneralUser-GS> (version 2.0.3, unmodified)
- **Licence:** GeneralUser GS License v2.0, in [`licenses/GeneralUser-GS.LICENSE.txt`](licenses/GeneralUser-GS.LICENSE.txt)
- **Release:** [`generaluser-gs-v2.0.3`](https://github.com/CyberDay1/craft-content/releases/tag/generaluser-gs-v2.0.3)
- **SHA-256:** `9575028c7a1f589f5770fccc8cff2734566af40cd26ed836944e9a5152688cfe`

The licence asks that sites featuring the bank do not link directly to the author's download
files, and either link to the author's website or provide their own copy. This repository is that
copy. For updates and the author's other instruments, visit his website.
